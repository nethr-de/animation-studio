# HyperFrames pitch video (route B)

Source: article section 07 · Engine, route B.

**What it does:** Turns a notes file into a 45-second pitch video with kinetic captions, using HyperFrames (HTML + GSAP).

**Use it for:** When you think in web pages, or the source is text.

**Placeholders:** `./notes.md`

**Tips:** Run it inside a HyperFrames project (`npx hyperframes init`). Preview with `npx hyperframes preview` and render with `npx hyperframes render`.

The prompt is in [`prompt.md`](prompt.md).
