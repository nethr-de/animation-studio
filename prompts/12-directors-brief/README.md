# Director's brief

Source: article section 10 · Overnight.

**What it does:** A brief for a long, multi-session production, with review gates, a critique loop and subagents per chapter.

**Use it for:** Music videos, long films and overnight autonomous runs.

**Placeholders:** `[DURATION]`, `[LOGLINE]`, refs, skills, API keys and budget, look, beat sheet

**Tips:** The viral overnight runs used briefs of 9,500 to 19,000 characters. Fill in every section; the more specific, the better.

The prompt is in [`prompt.md`](prompt.md).
