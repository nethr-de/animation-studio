# Prompt prototypes

Every prompt from Movez's article "How to build motion design studio with Opus 5.5 (Full-course)"
(https://x.com/0xMovez/article/2104216919033192746), one folder each.
Each `prompt.md` is copied word for word from the article; `[BRACKETS]` are placeholders to fill in.

Start Claude Code in the repo root so `CLAUDE.md` applies, then paste a prompt.
