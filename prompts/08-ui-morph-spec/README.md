# UI morph spec (XML)

Source: article section 06 · Spec.

**What it does:** The XML spec behind the most-bookmarked UI morph films: one container that never cuts, a cursor driving every state change, springs, and a beat grid.

**Use it for:** Product UI films and seamless loops.

**Placeholders:** Claude asks for the inputs itself (product, states, data, brand, track, formats).

**Tips:** The last frame must equal the first. Never use `will-change` on anything the camera scales.

The prompt is in [`prompt.md`](prompt.md).
