# Spring refactor

Source: article section 08 · Springs.

**What it does:** A one-pass refactor that replaces every easing curve with closed-form springs.

**Use it for:** When motion looks cheap or linear in an existing film.

**Placeholders:** none

**Tips:** Needs `lib/motion.js` (with `spring()` and `track()`) to exist.

The prompt is in [`prompt.md`](prompt.md).
